# Integration-of-single-cell-RNA-seq-and-ATAC-seq
This is an ongoing project on integration of single cell RNA-seq and ATAC-seq data using various multi modal data integration techniques.

The dataset is PBMC_healthy_donor_granulocyte_10K obtained from 10X genomics.

The single cell RNA-seq and ATAC-seq were processed seprarately initially using python packages and the integration was carried out using the mofa package.

The goal is to further use deep learning methods for integration as well.
